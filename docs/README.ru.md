Phrase Manager — локальный плагин uTools для организации повторно используемого текста. Иерархия Категория → Группа → Фраза подходит для ответов поддержки, шаблонов, промптов, фрагментов кода и заметок. Данные хранятся в локальной базе uTools и поддерживают резервное копирование в JSON.

## Возможности

- Создание, переименование, удаление, сортировка, перемещение и копирование групп, категорий и фраз
- Поиск, просмотр, горячие клавиши, пакетные операции, отмена и повтор
- JSON-копии, импорт/экспорт CSV iFlytek и импорт с помощью ИИ
- Генерация текста и заголовков, классификация и улучшение текста с помощью ИИ
- Тёмная тема, локальные шрифты и адаптивное редактирование

## Быстрый старт

1. Скачайте и распакуйте [последний релиз](https://github.com/realSilasYang/phrase-manager/releases/latest).
2. В инструментах разработчика uTools загрузите файл `plugin.json`.
3. Найдите в uTools «常用语», `Phrase Manager` или `Phrases`.
4. Выберите «Новая категория» или «Новая категория…». Категория — верхний уровень, внутри неё находятся группы; перед созданием можно указать оба имени.

## Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| `Ctrl+N` | Создать фразу |
| `Ctrl+Shift+N` | Создать категорию |
| `Ctrl+F` | Перейти к поиску |
| `Ctrl+S` | Сохранить текущую фразу |
| `Ctrl+Z` / `Ctrl+Y` | Отменить / повторить |
| `F2` | Переименовать группу или категорию под указателем |
| `Delete` | Удалить элемент под указателем |
| `Space` | Переключить предварительный просмотр |

## Поддерживаемые языки

Интерфейс доступен на упрощённом китайском, традиционном китайском Гонконга и Тайваня, английском, японском, вьетнамском, корейском, испанском, французском, бразильском и европейском португальском, русском, немецком и итальянском языках. Автоматический режим следует языку системы и использует упрощённый китайский при отсутствии совпадения.
